GitHub Data Storage

This app stores data in a JSON file in the GitHub repository using the GitHub API. You need a Personal Access Token (PAT) with repo / Contents: Read and write permission to save changes.

Create a token here (select "repo" scope for classic tokens, or "Contents: Read and write" for fine-grained).

Transfer Token to Another Device

Use this to copy your token to your phone or another browser without retyping it. Save your token above first, then generate a link or QR code and open it on the other device.

Note: the link contains your token. Only share it with your own devices and avoid sending it through chat/email. The token stays in the page URL (after #) and is never sent to a server, and this page removes it from the address bar automatically once loaded.

Scan this QR code with your phone's camera, then open the link. The token will load automatically.
